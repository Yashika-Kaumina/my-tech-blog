# 🚀 MyTechBlog

> A modern, responsive tech blog built with Next.js, Tailwind CSS, and TypeScript.

![MyTechBlog Screenshot](https://via.placeholder.com/800x400?text=MyTechBlog+Preview)

---

## ✨ Features

- 📱 **Fully Responsive** - Works on all devices
- 🌙 **Dark Mode** - Built-in dark/light theme toggle
- 📝 **Blog Posts** - Real projects with screenshots
- 🔗 **Live Demo Links** - Direct links to projects
- 📧 **Contact Form** - Get in touch easily
- 🎨 **Modern UI** - Clean, minimal design with gradients

---

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| **Next.js 16** | React Framework |
| **TypeScript** | Type Safety |
| **Tailwind CSS** | Styling |
| **React** | UI Library |
| **Vercel** | Hosting |
